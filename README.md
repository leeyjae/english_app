# 🛍️ Let's Shop! — English Shopping Practice

A Streamlit app for practicing English shopping phrases. Choose the buyer or seller role, select items, and build a shopping list.

## Features

- The buyer view shows a ₩2,000 budget and hides item prices.
- The seller view shows item prices and the shopping list total.
- Both roles can add items to the shopping list or remove them one at a time.
- Each role includes useful English shopping phrases.

## Run locally

Install [uv](https://docs.astral.sh/uv/) if it is not already installed, then run:

```sh
uv sync
uv run streamlit run streamlit_app.py
```
