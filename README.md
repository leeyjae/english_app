# 🛍️ Let's Shop! — English Shopping Practice

구매자와 판매자 역할을 선택해 물건을 고르고, 구매 리스트를 만들며 영어 쇼핑 표현을 연습하는 Streamlit 앱입니다.

## Features

- 구매자 화면에서는 물건의 종류와 가격을 확인할 수 있습니다.
- 판매자 화면에서는 같은 물건을 가격 없이 확인하고, 구매 가능 예산 ₩2,000을 볼 수 있습니다.
- 두 역할 모두 물건을 구매 리스트에 담거나 하나씩 뺄 수 있습니다.
- 역할별로 자주 쓰는 영어 쇼핑 표현을 제공합니다.

## Run locally

Install [uv](https://docs.astral.sh/uv/) if it is not already installed, then run:

```sh
uv sync
uv run streamlit run streamlit_app.py
```
